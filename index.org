applications in computer science. It's based heavily on (and depends
on the material for) the version of the course taught by [[https://www.cs.bu.edu/fac/crovella/][Mark
Crovella]].

* Schedule (Full)
** 09-03 Thursday (Lecture)
+ Week: 1
+ Title: Solving Linear Systems
+ Reading:
  + Required:
    + Geometric Algorithms (GA): [[http://mcrovella.github.io/CS132-Geometric-Algorithms/L01LinearEquations.html][Linear Equations]]
    + Course Notes (CN): [[https://nmmull.github.io/lecture-notes/linear-algebra/linear-equations/notes.html][Linear Equations]]
  + Optional:
    + Interactive Linear Algebar (ILA) 1.1: [[https://textbooks.math.gatech.edu/ila/systems-of-eqns.html][Systems of Linear Equations]]
    + Linear Algebra and its Applications (LAA) 1.1: Systems of Linear Equations
+ Topics:
  + systems of linear equations
  + solution sets and consistency
  + augmented and coefficient matrices
  + forward elimination and back substitution
  + row operations and row equivalence
+ Learning Objectives:
  + Recall the process of solving simultaneous linear equations.  You
    should be able to solve a linear system in 2-4 variables by hand.
  + Begin the formal study of linear systems, both geometrically (as
    collections of hyperplanes) and algebraically (as matrices that
    can be operated on).
+ Notes:
  + Assignment 1 is released
